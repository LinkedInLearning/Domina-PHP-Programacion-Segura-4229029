# Domina PHP: Programación segura

Este es el repositorio del curso de LinkedIn Learning `Domina PHP: Programación segura`. El curso completo está disponible en [LinkedIn Learning][lil-course-url].

![Nombre completo del curso][lil-thumbnail-url] 

Consulta el archivo Readme en la rama main para obtener instrucciones e información actualizadas.

Este curso te ofrece una inmersión profunda en la seguridad informática aplicada a la programación PHP. Dirigido a desarrolladores web, ingenieros de software y profesionales de TI con conocimientos básicos en PHP, este curso aborda amenazas y vulnerabilidades comunes en aplicaciones web. Aprende a proteger tu código contra ataques como SQL injection, XSS y CSRF, y adquiere las habilidades necesarias para implementar prácticas de desarrollo seguro. Desde técnicas básicas hasta estrategias avanzadas, este curso te equipa con los conocimientos y la mentalidad de seguridad necesarios para fortalecer la protección de tus proyectos PHP.

## Instrucciones

Este repositorio tiene ramas (branches) para cada uno de los vídeos del curso. Puedes usar el menú emergente de la rama en GitHub para cambiar a una rama específica y echar un vistazo al curso en esa etapa, o puedes añadir `/tree/nombre_de_la_rama` a la URL para ir a la rama a la que quieres acceder.

## Ramas

Las ramas están estructuradas para corresponder a los vídeos del curso. La convención de nomenclatura es Capítulo#_Vídeo#. Por ejemplo, la rama denominada `02_03` corresponde al segundo capítulo y al tercer vídeo de ese capítulo. Algunas ramas tendrán un estado inicial y otro final. Están marcadas con las letras i («inicio») y f («fin»). La branch i tiene el mismo código que al principio del vídeo. La branch f tiene el mismo código que al final del vídeo. La rama master tiene el estado final del código que aparece en el curso.
